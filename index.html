The problem

An agent that can act on your behalf usually has to hold the means to act. That's the part worth changing.

Agent with a token

  • Credential sits in the agent's environment
  • Open network access, direct to any host
  • No record of what it actually did

Agent with Passdesk

  • Only its Passdesk token, never your credentials
  • No network access outside Passdesk
  • Every call logged with its decision

How it works

Four steps, every time a tool gets used.

  1. 1

    Agent asks

    The agent sends a narrow request to Passdesk — push this branch, fetch these locked packages — using its own bearer token. It never sees a GitHub token, an npm credential, or raw network access.

  2. 2

    Passdesk checks policy

    Passdesk looks up the agent's grant list and the org's policy: which repos, which branches, which packages, which hosts. Anything outside that is denied with a reason.

  3. 3

    Passdesk acts

    Passdesk performs the call with its own credentials, read fresh per call. The agent's own egress is through Passdesk only, and Passdesk itself is held to an egress allowlist. Packages arrive as lockfile-pinned, hash-verified tarballs and wheels, and no install scripts run.

  4. 4

    Result filtered and logged

    Outgoing pushes and prompts are scanned for secrets and blocked if one turns up. What comes back is redacted, stripped of terminal escapes and wrapped as untrusted data before the agent sees it. The call (time, agent, tool, redacted arguments, decision) is appended to the audit record.

A denial, in practice

An agent asks to push straight to main. Policy says no, and says why.

Approve tools once

Approval lives in version control: per-agent config files, reviewed like code.

One grant file defines what an agent can touch: which repos, which branches, which packages, which hosts, and the limits on each.

Change the file, review it like any other diff, merge it. Once deployed, calls are checked against the new version.

Every call on the record

Passdesk keeps an append-only audit line for every call: time, agent, tool, redacted arguments, decision.
